# funder/

Put the funding announcement, the application instructions and the review
criteria for your mechanism here.

Claude reads this folder first and follows it over the rules stored inside the
skills, which were written in November 2026 and will age. The mock panel uses
the review criteria here to decide whether to score, and the biosketch skill
takes any newer form rules here over its own copy.

If it is empty, the skills use their stored copies and say so in the review.
