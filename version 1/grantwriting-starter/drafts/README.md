# drafts/

Your sections, written by you. The skills read from here.

| File | Read by |
|---|---|
| `aims.md` | `aims-checklist`, `biosketch`, `mock-panel` |
| `significance.md` | `significance-checklist`, `mock-panel`, `reference-check` |
| `innovation.md` | `significance-checklist`, `mock-panel`, `reference-check` |
| `approach.md` | `mock-panel`, `reference-check` |
| `summary.md` | `mock-panel`, for comparing your own two sentences against the panel's |

Each file starts with one comment line saying what goes in it. Paste your text
over it. Other sections of the application, such as the project summary or the
facilities page, can go here too, and the mock panel reads them along with the
rest. Figures go in `figures/`.

`biosketch-draft.md` appears here after the biosketch skill runs. It is the one
file in this folder Claude wrote, and it carries a line at the top saying so.
