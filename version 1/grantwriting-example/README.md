# Grant writing example

This is `grantwriting-starter` filled in. It holds a real application: an NIH
R21, *Crowdsourcing genomic predictors of disease progression using serious
games*, submitted by The Scripps Research Institute on 16 October 2012 under
PAR-09-219, with Andrew Su as PI and Benjamin Good as Co-Investigator. It was
not funded.

The application text is as submitted, mistakes included. Nothing in `drafts/`
has been improved, so what the skills find in it is what was there in 2012.

## What is where

| Folder | What it holds here |
|---|---|
| `drafts/` | Every written section of the application: Aims, Significance, Innovation, Approach with the preliminary data, project summary, facilities, personnel justification and resource sharing plan. Also `biosketch-draft.md`, written by the biosketch skill |
| `evidence/` | Good's CV and product list, the 24 cited references with identifiers looked up, both submitted biosketches, summaries of the letters of support, and a note on what the preliminary data rest on |
| `funder/` | The announcement, PAR-09-219, with its review criteria, and the NIH scoring scale |
| `checklists/` | Empty. No course checklist was supplied, so the checklist skills used their own |
| `reviews/` | One review from each of the five skills, run on 4 November 2026 |
| `ai-use-log.md` | One line per run |

Left out: the budget, the letters themselves (summarized instead), and PDFs of
the cited papers.

## How to use it

Read it next to the starter to see where each part of an application goes.
Then read `reviews/`: each review is what a skill produced from these files, not
a judgment anyone has checked. Every review ends with "What I could not source",
which shows what the folder was missing.

You can also open this folder as a project (Projects > + > Use an existing
folder) and run a skill yourself. Runs differ, so yours will not match the saved
review word for word. Comparing them shows which findings are stable.

The rules in `CLAUDE.md` and the skills in `skills/` are the starter's,
unchanged.
