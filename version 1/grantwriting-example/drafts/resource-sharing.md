# Resource Sharing Plan

Resources generated by the proposed research will include the software implemented to achieve both specific aims, the data collected through game play, and the consolidation of both into executable predictors of breast cancer progression. The source code for all relevant software will be available in an open code repository even as it is being developed and will be shared under a Creative Commons license. The collected data will be shared through websites associated with the project website. Care will be taken to ensure that personal data that may be collected in association with gameplay, such as usernames, passwords and IP addresses will be removed or anonymized prior to distribution. Any effective predictors of breast cancer progression generated through this work will be published and made accessible through web interfaces.
