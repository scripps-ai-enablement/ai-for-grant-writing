**Computer:** The Institute maintains a large 64-bit LINUX cluster, garibaldi, on the La Jolla campus to support scientific computation and data processing. The garibaldi cluster has a total of 3936 CPUs available for computations. Between local and shared disks the garibaldi cluster has over sixty Terabytes of disk space available for computational data. The garibaldi cluster uses the Portable Batch System (PBS) batch queueing system to ensure maximum system throughput and fair access. In addition, the Su Laboratory has six dedicated servers with up to 32GB of memory for computation and hosting web sites.

An extensive data communications network connects 19 buildings on campus. The major computer and data servers are connected via Gigabit Ethernet switches and routers. The majority of workstations, personal computers, and smaller computer servers utilize Fast Ethernet (100Mbps) and Gigabit Ethernet (1000Mbps) connections to the network.

The Institute operates a central data archival facility which uses a Silicon Graphics Altix 350 server, a thirty five Terabyte disk cache, and a large high speed StorageTek tape library. Current capacity is approximately 4000 Terabytes.

The Institute operates a central backup facility which provides periodic full backups and daily incremental backups of computer systems. The system uses a number of servers and two tape libraries housed in two buildings to provide disaster recovery.

Off campus resources such as massively parallel computers at various Supercomputer Centers are accessible via a full duplex 100 Megabit fast Ethernet Internet connection.
