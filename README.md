# Using AI for Grant Writing

Materials for a 90-minute seminar in TRBIO 431, Developing a Grant Proposal, at
Scripps Research. Each version ships two things that only make sense together: a
slide deck, and a folder students download and open as a project in the Claude
desktop app, so that everything the deck describes is in front of them while it
is being described.

The current materials are in [`version 1/`](version%201/), and the deck is
`Using AI for Grant Writing v1.pptx` inside it. A revised deck or starter goes
in a new numbered directory rather than over the top of this one, so the
highest-numbered directory is always the one to teach from.

## What students download

One zip, `grantwriting-seminar.zip`, attached to the
[latest release](../../releases/latest). Slide 27 sends people there by a short
link, `tinyurl.com/trbio431-ai`, which points at the release page rather than at
a file so that it keeps working when a later version ships. Unzipping it gives
three folders:

- `grantwriting-starter` is the folder as it ships: the rules file, the five
  skills, and a one-line placeholder for each part of a proposal, to be filled
  with a draft of your own.
- `grantwriting-example` is that same folder with a real 2012 R21 application
  (PAR-09-219) already in it, submitted and not funded, together with the review
  each of the five skills produced on that text, for anyone who turns up without
  a draft.
- `dinner-demo` is the three-layer demo the seminar opens with, for anyone who
  wants to run it themselves afterwards.

All three are attached to the release separately as well, for anyone who wants
only one of them. The skills are plain markdown and the rules file is twenty
lines, so both are worth reading before running anything (that is step 4 on
slide 28, and it is the step people skip).
