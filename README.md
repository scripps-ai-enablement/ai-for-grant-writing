# Using AI for Grant Writing

Materials for a 90-minute seminar in TRBIO 431, Developing a Grant Proposal, at
Scripps Research. Each version ships two things that only make sense together: a
slide deck, and a folder students download and open as a project in the Claude
desktop app, so that everything the deck describes is in front of them while it
is being described.

The current materials are in [`version 1/`](version%201/), and the deck is
`Using AI for Grant Writing v1.pptx` inside it. A revised deck or starter goes
in a new numbered directory rather than over the top of this one, so the
highest-numbered directory is always the one to teach from.

## What students download

Both folders are attached as zips to the
[latest release](../../releases/latest), which is where slide 26 sends people.

- `grantwriting-starter` is the folder as it ships: the rules file, the five
  skills, and a one-line placeholder for each part of a proposal, to be filled
  with a draft of your own.
- `grantwriting-example` is that same folder with a funded 2012 R21 application
  (PAR-09-219) already in it, together with the review each of the five skills
  produced on that text, for anyone who turns up without a draft.

The skills are plain markdown and the rules file is twenty lines, so both are
worth reading before running anything (that is step 4 on slide 26, and it is the
step people skip).

## Not here

The speaker notes point at an `instructor-only/` folder holding the 2012 summary
statement and a comparison between it and the mock panel. That material is
